# 역할 카드 — 과제 파악 책을 병렬로 10분 안에

카드 한 장 = 한 사람(세션 · 서브)의 일. 카드만 읽고 시작한다(RULES.md 전체를 읽지 않는다 — 필요한 규칙은 카드에 옮겨 담았다).
책 폴더 = `bookkit/books/<이름>/` · 아래 명령은 키트 폴더(AGENTS.md 가 있는 곳)에서 · 윈도우는 `python3` 대신 `py -3`.
과제 폴더 = `task_copy/`(키트 루트 · 지급 자료 복사본 — `$ontology` 1-0 ⓪ · 원본은 읽기만) · 독자 수준 = `$ontology` 0절 · 책 품질 기준 = `bookkit/book_example` 의 09(`task09/task09_kit.html`) · 10(`task10_guide_v3.html`)과 펼침 사진.

## 나눠 주는 말(Codex 서브 · 다른 세션에 그대로 붙여 넣는다)

분석(A0 가 끝나면 동시에):
```
서브를 동시에 띄운다(모델 · 강도는 역할 스킬 공통 절 대로). 서브마다 아래 한 줄을 준다 — 서브를 또 띄우지 않는다.
  «bookkit/cards/A2.md 를 읽고 그대로 한다. 책 = bookkit/books/<이름> · 과제 폴더 = <과제 폴더>. 끝나면 카드의 끝 신호 결과 한 줄만 보고»
  (A3.md 도 같은 말로 · 파일이 3개 이하면 A1.md 도 같은 말로)
파일이 4개 이상이면 A1 은 둘로 — 위 말 끝에 더한다:
  앞 묶음 «너는 A1 앞 묶음(합치는 쪽)이다. 네 파일: <이름들> · 뒤 묶음 파일: <이름들>»
  뒤 묶음 «너는 A1 뒤 묶음이다. 네 파일: <이름들> · 조각까지만»
```
PASS 를 보고한 서브에게 같은 서브로(새로 띄우지 않는다 · `followup_task`):
```
  «이어서 지도 — 카드의 «이어서 채울 온톨로지 칸» 대로. 끝나면 그 절의 끝 신호 한 줄만 보고»
```

## 모든 카드 공통(짧게)

- **집필 순서** — 계약 전에 숫자 없는 칸을 전부 끝낸다(숫자 칸도 문장은 써 두고 숫자 자리만 `{F['이름']}` — 없는 이름은 1차판 · 중간판에서 회색 «2차판» · 멈추지 않는다) → 보고하고 쉰다 → 지휘의 `followup_task` «<계약> PASS» 를 받으면 그 계약의 숫자 칸만 채운다(이름 맞추기 · 근거 숫자 — 문장을 다시 쓰지 않는다) → 끝 신호
- **항목 id** — 계약의 목록 항목마다 `id`(README 요구 R1 · 숨은 요구 H1 · 말하지 않은 곳 S1 · 질문 Q1(3장) / B1(부록 B) · 함정 T1 · 결함 D1 · 사실 F1 · 리포트 P1 · 조건 C1). 책의 번호(«질문 3» · 표 «#»)와 블록 ID · flowtree 출처가 이 id 를 쓴다 — 항목을 지우거나 끼워도 남은 id 는 바꾸지 않는다. 빠짐 · 겹침은 검사 FAIL(`check_contract.py … --add-ids` 가 빈 곳만 채운다)
- **숫자는 손으로 적지 않는다** — 계약의 `numbers` 를 `F['이름']` 로(계약 json 의 글은 `{F['이름']}`). 필요한 숫자가 계약에 없으면 지어내지 말고 그 칸을 비운 채 «필요한 숫자: 이름 · 무엇» 을 보고한다
- **비유 금지** — 다른 분야 상황을 덧씌우지 않는다. 그 과제의 파일 · 숫자로만
- **출처를 그 자리에서** — 처음 나오는 제약 · 숫자는 «12대 = 차량 파일 12행» 처럼. «N장 참고» 로 설명을 미루지 않는다
- **각주** — 입문 밖 용어는 처음 나오는 칸에 `("글", {"용어": "(영문) 설명"})`. 용어는 **그 칸 글에 글자 그대로** 있어야 한다(없으면 빌드 실패) · 본문에 ¹ 를 손으로 넣지 않는다(이중 표식) · 재생기 단계 글의 용어 각주는 재생기 칸의 `fn` 에
- **꾸밈** — `**굵게**` 핵심 · `!!빨강!!` 틀린 값 · `++초록++` 맞는 값 · 문단 5줄(약 250자) 이하
- 칸 주석의 «분량» 을 따른다 · 예시는 «예: book_example/template_examples.md · 칸 이름»(v3 — 다른 과제라 문구 · 숫자를 베끼지 않는다 · `contracts/example/` 도 본다)
