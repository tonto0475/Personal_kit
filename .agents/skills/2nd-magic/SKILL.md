# 2nd-magic — 무엇에든 질문
- Claude 세션이면 끝 줄이 «/2nd-magic 요청id» 로 온다 — 같은 뜻 · 아래 그대로

1. `./kit magic show 요청id` → 요청id = 메시지 끝 줄 $2nd-magic 뒤 낱말 · 질문 · 대상 · 답 자리(node · md · code · form · note · survey)와 명령이 나온다
2. 짧은 답(대상 맥락만 읽으면 됨)은 직접 · 조사가 필요하면 **내 서브에게** 조사 + 답 넣기를 시킨다(쓸 곳 = 그 답 자리뿐 · show 의 답 자리 명령을 지시문에 그대로 · 모델 · 강도 · «서브를 또 띄우지 않는다»)
3. 답 자리 명령: node → answer-node(--short 결론 60자) · md → answer-md · code → answer-code · form → answer-form · note → answer-note
   - node 가 유저가 고른 질문 노드면 그 노드 안 답 · 설문 노드면(show 에 «설문 노드 s…») 질문 = 그 설문 메모 · 답은 같은 answer-node 로 그 설문 노드 «질문 · 답» 칸에(새 노드 · 설문 답 votes 는 안 건드림)
   - note(책 스티커) = show 의 블록 ID 로 책 칸 · 계약을 읽고 바로 답(근거 칸 · 계약 id) + `--title '짧은 제목'`(20자 안팎 · 책 아래 질문 줄 행 이름 «Q1. 제목») — 답이 달리면 스티커는 화면에서 빠지고 질문 줄 행으로 간다
   - note 꼬리 질문(show 에 «꼬리 질문 t…» · 원 질문 · 원 답 · 앞 꼬리가 나옴) = 그 맥락을 이어 받아 answer-note 로 답(제목 없이) — 같은 행 안에 이어 달린다
   - survey(🪄 설문 ‹…› 질문 N개 — 유저가 설문에서 «질문» 을 고른 문항) = 문항마다 답을 answer-form 한 번에(설명 폼 · /tmp/sv) → show 의 «답을 넣은 뒤» 명령(`./kit hub send --to main`)으로 MAIN 에 알린다 · 다시 묻는 설문은 내가 만들지 않는다(MAIN · 등록 세션 몫)
   - show 에 «답 자리 없음 — 대화로 답» 이면(그래프 밖 Alt+R · 대상 없음) 노드 · 파일에 쓰지 않고 이번 턴 최종 답변으로 답한다
   - 메시지 · show 에 «지시: …» 가 있으면(Alt+R 지시 붙은 마법봉) 그 지시대로 답한다 · 답 자리는 위 규칙 그대로(질문 노드 · 설문 노드 · 스티커 안 · 새 노드 금지) · «지시:» 로 시작하면 지시 글이 곧 질문
4. 답은 짧게, 근거(파일 · 줄 · README 문장) · 자리는 스크립트가 찾는다(손으로 파일을 고치지 않는다 · magic.py 답 넣기는 저장소 쓰기 금지의 예외)
5. 상태 줄만(스크립트가 바꿈) · 누적은 안 한다
