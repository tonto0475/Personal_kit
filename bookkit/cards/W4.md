## 규칙(RULES 2절 · 5절 s4)
- 흐름: 가장 작은 경우(곳 셋)는 **전부 세면 된다**(성공 · 순서 표 + 작은 지도) → 크기가 늘면 곱으로 늘어 **실측 시간**으로 막힌다(전부 세기 표) → 그제서야 이름(이름 상자 하나에 **이름 둘까지**) → 맞혀 보기
- 쉬운 질문은 실제 곳 이름으로(순서 표의 곳) · 표를 읽는 한 줄 = 차이 숫자 **굵게** + «직관 규칙도 가장 짧지 않다»
- 방안 A 설명 = 규칙 두 줄 + 이름(휴리스틱) + 재생기 표 읽는 법 · 장단점 = **장점** … **허점** …(재생기 끝에서 본 것을 숫자로)
- 주의 상자 = README 에 없지만 붙을 수 있는 조건이면 방안 A 가 깨지는 곳
- 숫자는 `F['이름']` · 표의 값은 계약 그대로(손으로 옮기지 않는다)
- v3 서식: 🔴 절 제목에 번호를 붙이지 않는다(«4.1 먼저 쉬운 경우» ✗ → «OHT 한 대의 순서부터 — 전부 세면 되나» 모양 · 이 카드 제목의 4.1 · 4.2 는 구획 이름) · 주의 상자 220자 · 이름 상자 260자 · 문단 350자 안(RULES 6절 칸 길이표)
