# K2 — 저장 · 적용 (유저 확인 뒤 ✗ — hand_off 의 파일 · 함수 표에서 확인한 이름으로)

- 목표: 검사를 통과한 자료를 SQLite 에 **한 번에** 적용(전부 아니면 전무) · 적용할 때마다 판 번호 · 같은 자료를 두 번 넣어도 행이 늘지 않는다
- 복사: `python3 skeleton/copy_parts.py K2` → src/db/db_sqlite.py(connect · transaction · upsert)
- 쓸 파일(이것만): `src/db/저장.py`(계획표 이름 우선) · `tests/test_저장.py`
- 함수
  - `표_만들기(conn)` — 자료 표마다 고유 키 UNIQUE · `versions`(판 번호 · 시각 · 자료 지문 UNIQUE) 표
  - `적용(db_path, tables)` — 진입점: 한 트랜잭션 안에서 판 번호 하나 + 표마다 upsert → `{"version", "rows"}` · 같은 지문이면 새 판을 만들지 않고 기존 판 번호를 돌려줌
  - `판_목록(conn)` — 판 번호 · 시각 · 행 수
- 설정 칸(값 비움): 표마다 고유 키 열 «?»(계획표) · 판을 몇 개 남길지 «?» · 되돌리기 여부 «?»
- 할 일: 중간 실패면 전부 취소(시험: 둘째 표에서 일부러 실패 → 첫 표도 0행) · 같은 요청 두 번은 `scripts/race/race_check.py` 틀로
- 끝 신호: `python3 -m pytest -q tests/test_저장.py` 통과(두 번 적용 → 행 수 같음 · 판 번호 하나 · 중간 실패 → 0행) + `check.py --only K2`
- 하지 않는 것: 업무 규칙에 따른 덮어쓰기 · 병합 판단 · 이력 화면
