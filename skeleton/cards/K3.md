# K3 — 화면 틀 (확인 없이 시작 ○)

- 목표: 앱 껍데기와 화면 **자리**가 다 뜬다 — 내용은 «데이터 없음» 빈 상태로도 된다
- 복사: `python3 skeleton/copy_parts.py K3` → src/ui/(upload_check · progress_confirm) · 역할(로그인)이 README 에 있으면 `copy_parts.py auth` → src/core/auth_core · src/ui/auth_web · auth_nicegui
- 틀: UI_RULE 8절 표에서 모양 하나 → `ref/sample_apps/` 에서 필요한 함수만 · 색은 `src/ui/theme.py` 토큰
- 쓸 파일(이것만): `src/ui/app.py` · `src/ui/화면.py`(페이지 함수 묶음) · `tests/test_화면.py`
- 함수(페이지마다 하나 · 계획표 K3 행의 이름)
  - `첫_화면()` `/` — 상단 바 · 왼쪽 메뉴 · 하단 램프
  - `업로드_화면()` `/upload` — UploadCheckPanel: 업로드 → 미리보기 20행 → 검사 결과(K1 의 검사_리포트를 부를 자리) → «적용» 단추(K2 자리 · confirm)
  - `결과_화면()` `/result` — 결과 표(빈 상태) · 지도 자리 · 시간표 자리(README 에 있을 때만 카드 하나씩)
  - 역할이 있으면 역할마다 첫 화면 자리 + `/login`(add_login_page · require_role)
- 설정 칸(값 비움): 화면 문구 · 메뉴 이름 · 역할 이름(계획표 roles) · 표 열 순서
- 끝 신호: `python3 -m pytest -q tests/test_화면.py` 통과(NiceGUI user 픽스처로 페이지마다 열림 · 빈 상태 글자) + `check.py --only K3`(계획표 pages 가 전부 200)
- 하지 않는 것: 계산 · 저장 직접 호출(core · db 를 부르는 자리만) · 화면 세부 디자인
