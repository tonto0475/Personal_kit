## 규칙(RULES 5절 s5 · apx)
- 5장 들어가며 = 저장소 선택 · 화면은 계산하지 않고 완성본만 · 적용은 검증 뒤 한 번에 · 각주
- 주의 = README 원문 + 실험 숫자로 «왜 해당하나» · «이렇게» 1~2문장 · **해당 없음** 한 문단(왜 필요 없나 — 숫자 · 예: 파일 합계 크기)
- 부록 C 그림마다 한두 줄 · 화면 풀이 = 한 사람을 따라 읽기(계획 값으로) · 층별 표 분류 색 `(층, 맡는 일, 분류, 근거)`
- 상태 전이 그림: 한 대(한 건)가 거치는 상태가 규칙의 핵심일 때만 `{"fig": "상태전이", "P": D.figure("상태전이"), "caption": "…"}` — 상태 이름 상자 폭 안쪽(넘치면 «…»)
- `C_화면_그림` 이 계약에 없으면 비워 두고 보고(손으로 지어 그리지 않는다)
