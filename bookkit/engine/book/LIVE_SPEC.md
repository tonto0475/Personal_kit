# 조작 블록 명세 — «조작해 볼 수 있는 책» (2026-11-02)

> 책 엔진(`engine.py` · `assets\book.js` · `assets\book.css`)에 더하는 블록 4종 + 읽기 기록.
> 원칙: **안 만져도 읽히는 책 + 확인용 조작.** 조작 블록의 첫 화면(초기 상태)만 봐도 본문이 이해돼야 한다.
> 숫자는 빌드 때 파이썬으로 미리 계산해 심는다 — 브라우저에서 새로 계산하지 않는다(본문 숫자와 조작 결과가 어긋나지 않게).

## 공통 규칙

- 그림은 **SVG** 로 그린다(canvas 금지 — 오른쪽 축소판이 쪽을 복제하면 canvas 는 빈칸이 된다). `Svg(w, h)` 도우미 결과(글자)를 그대로 넣는다
- 블록 하나는 쪽 안에 들어가야 한다(폭 664px · 높이 약 990px — 넘으면 검사 «쪽보다 큰 블록»). SVG 는 `viewBox` + 폭 100%
- 조작 블록 바깥 상자에 `live` 클래스 — 두 페이지 모드의 «좌우 20% 누르면 넘김» 과 ← → 키 넘김에서 제외한다(블록 안 클릭 · 포커스 · 끌기는 넘김이 아니다)
- 판은 `transform: scale(--k)` 로 줄여 보인다. 좌표가 필요한 조작은 SVG 기준 좌표(getScreenCTM)로 바꾼다
- 조작 지시 한 줄(`task=`)을 블록 위에 노란 띠로 — «차당 건수를 30 으로 놓아 봐 → 차가 몇 대 늘어나나?» 처럼 **무엇을 놓고 무엇을 볼지**. 안내 없는 자유 조작은 초보에게 시간만 먹는다
- 블록마다 데이터는 `<script type="application/json">` 으로 블록 안에 심고 book.js 가 블록을 쪽에 담은 뒤 한 번 초기화한다. 블록 하나 데이터 500KB 넘으면 빌드 경고
- 스티커 · 각주(`fn=`) · `id=` · ↩ 앵커는 다른 블록과 같다

## 1. `w.stepper(steps, title=None, caption=None, table=None, task=None, auto_ms=900, fn=None, id=None)` — 단계 재생기

알고리즘 · 처리 과정을 한 단계씩 넘겨 본다. 교육 정책 F4(실행 순서 추적표)를 손으로 넘기는 판.

- `steps` = `[{"svg": SVG 글자, "text": "이 단계 설명(꾸밈 글)", "row": 표 행 번호 또는 None}, …]`
- `table` = `{"header": [...], "rows": [[...], ...], "small": True}` (선택) — 그림 아래 추적표. 지금 단계의 `row` 행이 강조되고, 아직 안 온 행은 흐리게
- 단추: ⏮ 처음 · ◀ 이전 · ▶ 다음 · ⏯ 자동 재생(auto_ms 간격) · 단계 표시 «3 / 12». 블록에 포커스가 있으면 ← → 가 단계를 움직인다(쪽 넘김 아님)
- 초기 상태 = 0단계(또는 `start=`). 첫 단계 그림이 정적 그림 역할을 한다

## 2. `w.slider(params, frames, render="svg", metrics=None, task=None, predict=None, title=None, caption=None, fn=None, id=None)` — 조건 슬라이더

조건을 바꾸면 결과(그림 · 지표)가 바뀐다. 결과는 조건 조합마다 미리 계산한 것.

- `params` = `[{"key": "cap", "label": "차당 건수", "values": [30, 45, 60], "default": 45, "unit": "건"}, …]` — 슬라이더는 values 칸에만 멈춘다. 2~3개 권장
- `frames` = `{"30|1.5": {"svg": SVG 글자, "metrics": {"필요 차 대수": 12, "최악 대기 배율": 2.1}, "note": "꾸밈 글(선택)"}, …}` — 열쇠는 params 순서대로 값을 `|` 로 이은 글자. 빠진 조합은 «계산 안 함» 표시
- `metrics` = 보여 줄 지표 순서 · 형식 `[{"key": "최악 대기 배율", "fmt": ".1f", "unit": "배", "bad_above": 2.0}, …]` — 기준을 넘으면 빨강. 기본 조합 대비 차이를 옆에 작게(▲ +3)
- `predict` = `{"q": "차당 30 건이면 차는 몇 대?", "at": {"cap": 30}, "metric": "필요 차 대수"}` (선택) — 숫자 입력칸 + «확인» → 슬라이더를 그 조건으로 옮기고 실제 값 · 차이를 보인다(교육 정책 F8 · 예측 오차)
- 초기 상태 = default 조합

## 3. `w.open_full(path, label, note=None, id=None)` — 크게 열기

쪽에 안 들어가는 큰 조작 화면(키트 whatif.html 같은 HTML 한 파일)으로 가는 단추.

- 빌드가 `path` 파일을 출력 옆 `<doc>__<파일이름>` 으로 복사하고 새 탭 링크를 단다(배포할 때 같이 올린다 — 빌드 끝에 «함께 배포할 파일» 목록 출력)
- 쪽 안에는 단추 + 한 줄 설명만

## 4. 읽기 기록 (META `"reading_log": True` 인 책만)

- 쪽(두 페이지 모드는 펼침)마다 **화면에 보인 시간**을 localStorage 에 누적한다. 탭이 숨겨져 있거나(visibilitychange) 60초 넘게 입력(마우스 · 키 · 스크롤)이 없으면 세지 않는다
- 조작 블록 사용 횟수(단계 넘김 · 슬라이더 이동 · 확인 누름)도 블록 ID 별로 센다
- 오른쪽 아래 버튼 줄에 «기록» 버튼 → 쪽별 시간 표(장 이름 · 쪽 · 초, 긴 순 정렬 보기 전환) + «복사»(JSON) · «초기화»
- 서버로 보내지 않는다(로컬 저장만)
