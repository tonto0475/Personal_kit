# A0 — 문제파악: 받은 자료 전부 스캔 → work/files_scan.json · inventory.md (4분)

**읽을 것**: `<키트>/task_copy/` 의 **README 를 뺀 모든 파일**(키트 · 키트가 만든 것 · .git · 점 폴더는 제외) — 읽기만. **README 는 읽지 않는다**(README 를 모르는 채 자료만으로 본다 — A1 이 README 를 읽고 보는 것과 다른 눈)
**쓸 것**: `<책>/work/files_scan.json` · `<책>/work/inventory.md` 뿐 · 다른 파일은 고치지 않는다 · 커밋하지 않는다

## 할 일
1. 파일마다 한 줄: 경로 · 종류 · 크기 · 무엇(한 문장) · 읽음 / 세어 봄 / 못 읽음(이유) — 못 읽은 파일은 숨기지 않고 목록으로
2. CSV 는 파일마다 `python3 scripts/ontology/profile.py <파일>` 로 세고, **칸(열)마다** 적는다: 결측(빈 칸 · NA · - 같은 빈 값 표기) 수 · 이상값(범위 밖 · 부호 · 단위 어긋남) · **다른 줄과 다른 몇 줄**(형식 · 부호 · 표기만 다른 줄 — 실제 원본 줄 번호와 값) · 경계값(최소 · 최대 · 날짜 처음 · 끝)
3. 파일 사이 이어지는 열(키 후보)과 안 이어지는 값 수
4. PDF · 문서 · 이미지는 제목 · 쪽 수 · 무엇이 들었나 한 문장 · 못 읽으면 못 읽음

## 끝 신호
`inventory.md` = 파일 표(1) + CSV 칸 표(2) + 이어지는 열(3). 한 줄 보고: «파일 N · 열 M · 특이점 K · 못 읽은 파일 목록(없으면 없음)»

## 메인이 이어서(지휘)
- README 를 읽고 A0 결과를 대 본다 → «README 요구는 있는데 파일에서 확인 안 된 정보» 목록을 만든다(없으면 없음)
- 그 목록 = 지도 «확인할 것» 후보로 A2 에 넘긴다 · A1 은 A0 산출물이 있으면 다시 세지 않고 그 숫자로 시작한다
