## 규칙(RULES 2절 · 5절 s4)
- 방안 B = 적어 주는 세 가지(**목적** · **제약** · **시간 한도**) · 장단점 숫자로 · 고치기 설명 = 처음 답 → 한 곳씩 바꿔 줄면 받아들이기 + 이름(국소 탐색) · 결과 = 몇 번 바꿔 얼마 → 얼마
- 규칙은 조건이 든 한 문장(«~이면 ~다») **굵게**
- 세 단계 띠(`figs.strip3` 칸 — 상자 3개 · 상자마다 3줄 안쪽) = 방안 결과 → 이어 붙이기 → 검증기
- **↩ 1장 되돌아보기** = 1장 큰 흐름 그림의 숫자를 **그대로 다시** 적고 지금 새로 보인 것
- 맞혀 보기 = 조건 하나를 바꾸면? (답은 조건별 표의 값)
- 선택표 `{"header": ["질문", "이렇게 정해지면", "→ 방안", "근거(실측)"], "rows": […], "cls": "wr lf", "small": True, "caption"}` — 질문 = 3장 번호 · 근거 = 계약 숫자
- 추가 그림: 시각마다 필요한 수 vs 보유가 결론이면 `{"fig": "시각막대", "P": D.figure("시각막대"), "caption": "…"}`
- v3 서식: 절 제목에 번호 없음(«방안 B — 솔버에게 맡기기» · 이 카드 제목의 4.3~4.5 는 구획 이름) · 선택표 **12행 이하**(v3 9행 — 질문 하나에 답 두 갈래면 «이렇게 정해지면» 칸에 «예 / 아니오» 를 한 행으로) · 되돌아보기 210자 · 문단 350자 안(RULES 6절 칸 길이표)
