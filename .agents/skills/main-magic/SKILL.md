# main-magic — 고른 노드를 종류로 서브에게 나누기
- Claude 세션이면 끝 줄이 «/main-magic 요청id» 로 온다 — 같은 뜻 · 아래 그대로

1. `./kit magic show 요청id` — 요청id = 메시지 끝 줄 $main-magic 뒤 낱말(m월일-시분초-4자리) · 고른 노드 · 함수 표 · 요약 · 종류별 «할 일 / 검증 할 일 / 질문 할 일» 이 나온다(상태 줄은 스크립트가 바꿈)
2. 작업 노드마다 `./kit graph --role main start <id>` → **구현 서브에게 시킨다**(쉬는 서브 = followup_task · 내가 코드를 쓰지 않는다 · main 1-7)
   - 지시문: 목표(노드 제목 · 요약) · 읽을 것(hand_off 그 섹션 · show 의 함수 표) · 쓸 파일(섹션 수정 범위만 · 밖이면 멈추고 보고) · 끝 신호(시험 명령 · 커밋) · 보고 형식 · 모델 · 강도 · «서브를 또 띄우지 않는다»
   - show 의 함수 표(파일 | 함수 | 설명 | ⭐) 이름으로 만든다 · «이름 바뀜: 옛 → 새» 가 있으면 그 이름으로 코드 · 시험 · 문서를 바꾸는 일까지 서브에게 시키고(CODE_RULE 9-1) 끝나면 `./kit graph --role main funcs-ack <id>`
3. 서브 커밋을 받으면 서브 보고의 끝 신호(시험 명령)만 한 번 돌려 통과면 done <id>(diff 를 읽지 않는다 — 검토는 검증관 · 검증을 기다리지 않는다)
4. 검증 노드마다 **검증관에게 시킨다**(followup_task · 고정 양식 = 섹션 번호 · 성공 기준 · 커밋 해시 · 볼 파일 · 축만 · 구현 설명 없음 · main 1-7)
   - 같은 요청의 작업 노드가 대상이면 그 작업의 커밋을 받은 뒤에 준다
   - verify-start · run 은 검증관이 `./kit graph --role insp` 로 직접 남긴다 · 실패 왕복은 검증관 ↔ 수정 서브(내가 받는 건 답 한 줄)
5. 질문 노드마다 **놀고 있는 서브에게 답을 시킨다**(followup_task · 지시문 = 노드 id · 대상 노드 · 쓸 곳 = 그 노드만 · `./kit graph --role 2nd answer-start <id>` → answer <id> --short '결론(60자)' '본문') — 놀고 있는 서브가 없으면 먼저 끝나는 서브에게 줄을 세운다
6. 섹션을 시작 · 끝낼 때 hand_off «섹션 작업 순서» 실제 칸에 한 줄 덧붙인다(서브에게 · `./kit handoff order-add <섹션> --actual "…"` · 기존 줄은 안 고침)
7. 설문 노드(🪄 설문 ‹…›(s…) 결정: ‹선택지› · 메모 … — 유저가 답한 설문을 골라 MAIN 마법봉 = 설문에 답한 것) → hand_off 반영 → `./kit graph --role main survey-ack <id> '무엇을 했나'` → 그 설문이 붙은 작업 시작(위 2~3) · 맨 앞 설문(«이 범위로 시작» 등)은 카드 P(bookkit/cards/P.md 지휘) 대로 범위 승인 · 그 밖 노드(요구 · 결정 · 파일)는 맥락만 · «멈춤»(작업 · 검증 · 질문 · 답한 설문 노드 0개)이면 노드를 만들지 말고 유저에게 묻고 턴을 끝낸다
   - **지시 붙은 마법봉**(Alt+E — 🪄 … 끝에 «지시: …» · 노드 없이 «대상: 파일 · 줄 / Git / 책 스티커» 또는 «대상 없음» 만 올 수 있다) = show 의 대상 + 지시대로 서브에게(위 2~5 · 노드가 있으면 그 노드에 지시를 얹어서) — 멈추지 않는다
8. **설문 요청**(🪄 설문 ‹…› 확정 N개 — 유저가 설문 화면에서 제출하면 서버가 보냄) — show 에 확정 문항 · 결과 전체 명령이 나온다 → 결정 문서에 반영(survey 스킬 4절) → 설문 · 결과 파일과 같이 커밋 → 반영한 결정대로 작업 시작(작업 → 구현 서브 · 검증 → 검증관 · 위 2~6) · 추가 지시가 있으면 따른다
   - 2ND 가 «설문 … 질문 답 · 설명 폼 id» 를 보내오면 그 답을 배경에 넣어 다시 묻는 설문을 만든다($survey)
9. 서브가 일하는 동안 턴을 끝내지 않는다(긴 wait_agent — 내가 턴을 끝내면 서브 완료로 안 깨어난다) · 끝나면 상태 줄 · 큰 단위였으면 `./kit hub log` 한 줄($codex-hub)
