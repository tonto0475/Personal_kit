# K1 — 입력 파이프라인 (유저 확인 뒤 ✗ — hand_off 의 파일 · 함수 표에서 확인한 이름으로)

- 목표: 자료 파일마다 읽기 함수가 있고, 원본을 **고치지 않고** 문제 줄을 검사 리포트로 낸다(처리 결정은 비움)
- 복사: `python3 skeleton/copy_parts.py K1` → src/core/(csv_load · quality)
- 쓸 파일(이것만): `src/core/입력.py`(계획표가 다른 이름을 정했으면 그 이름) · `tests/test_입력.py`
- 함수(계획표 K1 행 · 유저가 고친 names 우선)
  - 파일마다 `<자료>_읽기(path)` — read_csv_auto + clean_columns · 필수 열 검사(require_columns) · 열 형 변환은 **실패해도 줄을 버리지 않고** 리포트 줄로
  - `검사_리포트(tables)` — 결측 · 중복 키 · 형식 오류 · 범위 밖 → `[{"file", "line", "kind", "raw"}]`(줄 번호는 원본 줄 · 머리줄 = 1)
  - `전부_읽기(task_dir)` — 진입점: `{"tables": …, "report": …}`(README 3절 표)
- 설정 칸(값 비움): 필수 열 목록(계획표가 적은 열 이름) · 범위(최소 · 최대 «?») · 고유 키 열 «?» — `config/config.yaml` input 아래
- 할 일: 처리 건수 = 입력 건수 단언(CODE_RULE 6절) · 리포트 건수를 log_event 로 «입력 N · 문제 M»
- 끝 신호: `python3 -m pytest -q tests/test_입력.py` 통과(파일마다 행 수 · 일부러 넣은 문제 줄 하나가 리포트에 나오나) + `python3 skeleton/check.py --task <과제> --only K1`
- 하지 않는 것: 문제 줄을 고치기 · 버리기(hand_off 결정 뒤) · 화면
